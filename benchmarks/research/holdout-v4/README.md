# holdout-v4（D036 正式对照用，2026-10-26 冻结）

**标签为 AI 共识标注，未经人工核验。** 只用于 D036 的一次正式对照；对照跑完后不再称“未见”。

## 资料

- 16 篇 ACL Anthology 论文，8 组主题对（文本向量、检索预训练、提示压缩、幻觉检测与核验、引用与可核验性评估、示例检索、查询改写与扩展、RAG 基准），全部为 2022–2024 年发表，按 ACL Anthology 规定以 CC BY 4.0 许可；与此前所有数据集及中文演示库不重叠。明细见 `corpus.json`。
- PDF 本地保存于 `data/evaluation/holdout-v4/papers/`（不进版本控制），哈希见 `freeze.json`。

## 知识库（真实链路）

1. 每篇入库正文约前 12 页，一篇一个知识集合；抽取 17 次调用（deepseek-v4-flash），得到 426 条候选。
2. DeepSeek 与 qwen3.8-max 各在一份副本上用项目自身的 AI 预审独立审核；两者一致才批准或驳回（103 条批准）。
3. **D036 修订（用户批准，出题与对照之前）**：90 条分歧由 kimi-k3 第三家族判定，三模型多数决（2/3）；端点已入库但从未被判定的关系按原规则补判（本次无符合条件者）。最终 136 条正式知识（每篇 1–22 条，见 `corpus.json` 的 `approved_claims`），其余留待人工。
4. 评测知识库本地保存，冻结快照哈希见 `freeze.json`。

## 题目

- 75 道中文题（问题中文、资料英文）：可回答 50（单篇 30、跨篇 20），证据不足 12，越界 13。
- Codex（gpt-6-astra）依据已审核知识出题两轮：第一轮可回答题过少（33/80），第二轮按计划调整配比并去掉系统用语。每个要点都引用已审核知识中的证据 id。
- 标注：DeepSeek 与 qwen3.8-max 各自盲标可答性（只见题目、允许论文与其已审核证据，不见草稿答案），再非盲核查每个要点能否由所引原文直接支持。43 题完全一致；32 题由 Claude 仲裁（非盲）：4 题收窄题面到所引证据直接支持的部分，其余维持原标签，理由逐题写在 `annotation.adjudication`。两名标注者对 50 道可回答题的要点支持核查全部通过。

## 调用

准备阶段真实调用 156 次（上限 250）：抽取 17，审核 DeepSeek 32 / qwen 30 / kimi-k3 21（其中 5 次因推理占满 token 预算无输出，按批次重试），标注 DeepSeek 28 / qwen 28。另有 Codex 本地会话 2 次。网关模型经辅助网关调用，不是项目依赖。费用未知。

## 局限

- AI 共识标签，非人工核验；Claude 仲裁非盲。
- 严格审核下知识较稀，部分论文只有 1–5 条正式知识，对应主题对的题目以越界、证据不足或跨篇一侧为主；compact-v1 与现标准在证据少的范围内可能装入相同证据。
- 单一生成模型；题目共享证据，题间不独立。
