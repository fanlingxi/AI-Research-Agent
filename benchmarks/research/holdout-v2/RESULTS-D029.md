# holdout-v2 默认策略对照结果（D029）

日期：2026-10-12。**标签为 AI 共识标注（Claude 起草与仲裁，GPT/Codex 与 DeepSeek 独立交叉标注），未经人工核验。** 结论只适用于这 24 道保留题、8 篇 ACL 论文和单一生成模型，不代表普遍回答准确率。

## 设置（执行前预登记，见 DECISIONS D029）

- A＝当前默认：legacy 检索 + `research` 工作流。
- B＝候选整链路：dense-v1 向量检索 + coverage-v2 选材 + `research_v7`（含 D028 锚点归一化）。
- 24 道 holdout 题 × 2 臂 = 48 次运行，A/B 交替；生产链路（审核入口入库 → 冻结快照 → Worker → 最终提交），独立评测数据库，正式知识库指纹前后一致。
- 生成模型 `deepseek-v4-flash`；生成付费调用 97 次，另有 B 臂选材调用；评分时 DeepSeek 裁判 44 次调用，失败 0 次。已记录用量约 132 万输入 / 8.5 万输出 tokens，另有 49 条调用记录没有用量信息；实际费用未知。
- 评分：DeepSeek API 裁判 + Claude 裁判各自独立对照标签判分，两者不一致时保守计（任一裁判判未覆盖即未覆盖，任一裁判判违规即违规）。两名裁判对 A 臂 19/23、B 臂 17/21 份报告的判定完全一致。

## 结果

| 指标 | A 默认 | B 候选 | 门槛 | 是否满足 |
| --- | --- | --- | --- | --- |
| 完成率 | 23/24（95.8%） | 21/24（87.5%） | B ≥ A | 否 |
| 要点覆盖率 | 13/50（26%） | 33/50（66%） | B ≥ A + 10pp | 是 |
| 越界断言率 | 1/24 | 1/24 | B ≤ A | 是 |
| 拒答正确率（4 题） | 4/4 | 2/4 | B ≥ A | 否 |

**结论：未满足切换门槛，默认保持 A；B 继续作为可选策略。**

## 诊断（不改变上述结论）

- B 的要点覆盖率明显更高，说明向量检索 + 覆盖选材 + 结构化生成能找到并写出更多被问到的事实；A 的报告更常停留在泛泛描述。
- B 未完成的 3 次中，2 次为 `needs_review`：分析步骤先把原题改写，最终生成时模型从改写版复制“回答分项”，被逐字校验正确拒绝（例如 noise-q8 把原题中的“。请依据”改写成“，如何依据”）。这是 v7 提示设计缺陷：校验对照原题，模型看到的却是改写版。
- 拒答失败中的 longtail-q7，B 实际已明确“在仅允许 PopQA 的约束下无法给出”，未用外部知识作答；两名裁判因措辞偏“证据不足”而非“越界”判为不符。该判定偏严，但按预登记口径计入。
- multistep-q8 两臂均失败（相同问题），不影响 A/B 比较。

## 下一步建议

1. 新建工作流版本（如 `research_v8`，保持 v7 可重放）：在最终生成提示中直接给出原题文本，并要求 `question_part` 只从原题复制；越界题明确要求说明“超出允许资料范围”。
2. 只在 holdout-v2 的 **dev** 拆分上调试；切换默认需要一套新的未见保留集（holdout-v2 的 holdout 拆分已用于本次决定，不再称“未见”）。
