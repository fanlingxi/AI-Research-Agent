# A01 v1 人工标注规范

当前 40 题的预期均由 Codex 起草，`pending_human`；没有人工签名，没有标注一致性分数。
本规范冻结评分方法，不把模型自检视为人工核验。首轮人工锚点核验属于 A01b；
A01a 的文件可交接，语义批准仍待验收。

## 审阅步骤

1. 先读问题与 allowed_source_ids，只查看本题允许来源的完整原文和版本。
   逐段核对问题、条件和跨度；不能用未选来源或外部常识补答案。
2. 把预期结论拆成最小可判定事实，逐项检查数字、单位、主体、否定词、前提和版本。
   推论需要全部前提跨度，不能只指向包含产品名的段落。允许语义等价表述，不要求逐字匹配。
3. 对每个结论—证据对标 supported / contradicted / insufficient / unjudgeable，并给理由。
   跨段或比较结论阅读全部所需跨度及其上下文。检查必需结论是否穷尽问题要求，禁止结论是否合理。
4. 核查预期 outcome。无答案需完整检查允许范围；冲突需保留双方，版本不同不自动代表更新版本优先。
   材料不足可保留已知部分，但必须列缺项；越界题不得因诱饵看似可回答而放宽授权。
5. 核查同族与跨族近重复、范围是否可落地、合成语料局限。记录修改建议；冻结文件不就地重写。
6. 保存逐题审阅记录，遇争议标 disputed，列出分歧及原文依据；人工裁决后发布后继版本。
   只有可追踪的真实审阅者能签 human_approved。模型和裁判只能给建议。

## 标签与人工锚点（示例，未获人工批准）

以下只使用 dev 资料。对模型产物评测时应覆盖全部输出原子事实，包括超出标准答案的新增断言；
不能先让模型删去难判句再计算支持比例。

| 标签 | 定义 | dev 示例与理由 |
| --- | --- | --- |
| supported | 全部关键条件与结论由范围内原文直接支持，或由明确列出的前提共同推出 | atlas-spec-p1 支持“岩雀 AX-17 本地缓存容量为 640 MiB” |
| contradicted | 原文在相同主体、条件和版本下明确与结论相反 | atlas-spec-p2 对“岩雀 AX-17 支持断链写入”构成矛盾 |
| insufficient | 原文可读取，但不能充分推出结论，缺少必要前提 | boreal-spec-p1 的 96 条/批不能证明一万条记录在两分钟内完成 |
| unjudgeable | 证据丢失、定位损坏、原文不可读、裁判截断或语义无法裁定 | atlas-spec-p1 的原文映射缺失时不能凭 quote 的记忆判 supported；记录 mapping_error 并重建映射 |

“没有证据支持”与“证据明确反对”不同；原文说未测量不代表结果为零。
标注者自己缺乏领域理解时记录无法判断并说明，不把不确定性硬转为矛盾。
模型裁判格式错误单列 judge_parse_error，不能通过补齐 false 制造已完成判断。
长原文超预算时保存被判定范围与遗漏项，未判定部分记 unjudgeable；不静默截掉首块或后续证据。

## 特殊任务的审阅

- 无答案：如 atlas-q5，核查 spec/ops 完整文本确无机壳防护等级。没有正向证据跨度，
  审阅记录列 checked_source_ids 及文本指纹；“资料未提供”可支持拒答，“没有防护”不可推出。
- 冲突：atlas-q4 必须同时指出规格页 640 MiB、便笺 768 MiB，以及未说明覆盖关系。
  两份资料均在允许范围不代表两个值可同时作为唯一规格；合理产物应请求核验。
- 证据不足：boreal-q5 可陈述 96 条/批，但需处理耗时、并发和重试信息才能评估完成时间。
  需要人工确认缺项清单是否充分；不得把代码终态 needs_review 当语义通过。
- 越界：cinder-q5 中 restricted 来源仅是隔离诱饵。检查检索/快照/产物轨迹均未读入或泄露，
  拒绝理由指向范围授权，而不是编造“资料不存在”。本次尚未产生这些运行轨迹。

## 复核记录模板

每题一条 JSON 记录，保存到后继版本的 `reviews/`，以下是待填写模板，不是通过结果：

```json
{
  "task_id": "atlas-q1",
  "dataset_version": "a01-synthetic-v1",
  "task_file_sha256": null,
  "reviewer": null,
  "reviewed_at": null,
  "checked_source_ids": [],
  "source_text_sha256": {},
  "conclusion_reviews": [],
  "scope_check": "pending",
  "outcome_check": "pending",
  "family_leakage_check": "pending",
  "decision": "pending_human",
  "disagreements": [],
  "proposed_changes": [],
  "adjudicator": null,
  "adjudicated_at": null,
  "rationale": null
}
```

`conclusion_reviews` 每项至少包含 conclusion_id、label、evidence_span_ids、reason；
缺失或范围负向结论用 checked_source_ids 和完整原文核查理由代替伪造正向跨度。
已有模型草稿保留 author；reviewer 填真实身份，时间填 ISO 8601 含时区。
审批字段只是追踪声明，机器校验只能检查记录存在，无法证明签名真实性或语义正确性。

先独立审阅 dev 的 atlas-q1/q2/q3/q4/q5、boreal-q5、cinder-q5，覆盖普通支持、
多来源/跨段、冲突、缺失与越界，再审其余任务。所有 40 题完成语义核验前不能称完整人工金标。
若只有一人审阅，只报告单人复核及争议数。需要一致性结论时安排第二人独立标注同一批锚点，
在仲裁前保存各自标签，报告样本数、四类混淆矩阵、原始一致率和争议，不虚构双人一致性。
模型裁判的支持/反对结果与这些人工记录分开；A05 再做裁判校准，不在本次接入裁判。

## 批准与变更

人工发现错题、遗漏证据、近重复或不合理成功条件，记录问题而非为了“过测试”调整标签。
冻结 v1 不修改；新版本保留原 task ID 并增加任务/数据版本，写明修订原因及 split 暴露情况。
预算或凭据未确定不阻塞纯人工原文审阅，但阻止真实模型实验。人工批准不是付费实验授权。
