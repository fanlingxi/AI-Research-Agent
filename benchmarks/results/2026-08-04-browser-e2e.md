# Knowledge Core 浏览器 E2E：2026-08-04

## 环境边界

- UI：真实 `app/ui/streamlit_app.py`
- API：真实 `app/api/main.py` 路由
- worker：真实 `KnowledgeWorker`
- 事实库与 Vault：`/tmp` 隔离临时目录
- PDF、抽取、投影、查询和 LLM：本地确定性 fixture
- 外部数据/费用：无；未调用 DeepSeek，未修改现有 Knowledge Base

## 浏览器执行链路

1. 在“知识入库”提交主题“浏览器端到端验证”和 fixture PDF；页面返回持久任务 ID。
2. worker 领取任务；“审核队列”显示 3 个候选（2 实体、1 关系）。
3. 点击“批准所有无冲突候选”；页面刷新后 ingestion 为 `completed`、待审核为 0。
4. 在“研究报告”提交问题；页面先显示 `queued`，刷新后显示 `completed`。
5. 报告页显示 grounding、引用覆盖、引用忠实度和结构评分均为 100%。
6. 证据包显示 `[E1] Browser E2E Paper · p.1` 和对应原文。

## 结论

真实浏览器交互已经贯通“入库—审核—正式投影—检索—生成报告—查看证据包”。该 E2E 证明 UI/API/worker 状态契约，不替代真实 LLM 内容质量、外部 API 成本或开放域检索评测。
