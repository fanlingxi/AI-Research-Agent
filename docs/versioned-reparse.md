# 带版本的重新解析（D031）

解析器标识为 `pypdf-v2`。已有文档的解析版本不回填；来源版本仍取解析正文的 SHA-256。内容不变时不会只为升级解析器标识而建立新版本。

## 数据与接口

增量迁移 `0021_source_reparse.sql` 增加：

- `sources.superseded_by_source_id`、`sources.superseded_at`：只记录版本取代关系，不改写来源正文或证据。
- `ingestions.reparse_payload_json`：保存重解析结果、原来源标识、内容哈希和解析器版本。Worker 与失败重试复用这份输入，避免队列等待期间 PDF 文件变化。

| 接口 | 行为 |
| --- | --- |
| `POST /api/knowledge/documents/{document_id}/reparse` | 只读取登记的、存在的本地 PDF，沿用原文档入库任务的集合与页数上限。相同内容返回 200、`status=unchanged`、`ingestion_id=null`；不同内容返回 202 和入库任务 ID。重复提交复用任务，已有相同来源内容版本也复用其任务。 |
| `POST /api/knowledge/sources/{source_id}/activate` | 要求至少一条已发布知识的证据，否则 409。在短事务内清除目标版本的取代标记，并将同一 `canonical_uri` 的其他已发布版本标记为被目标版本取代。再次启用旧版本可切回。 |
| `GET /api/knowledge/sources/{source_id}/activation-preview` | 在单个只读事务中预览启用影响。返回将取代的版本数、将暂不显示的已发布实体和关系数量，以及各最多 20 个名称样例。未知来源返回 404。 |
| `GET /api/knowledge/documents?ingestion_id=...` | 返回解析版本、来源版本、发布状态、生效状态、版本记录及可否重解析，供知识库页面使用。 |

重解析预检在事务外进行，入队时再次核验原文档内容哈希及所属集合。URL 导入的文档从本地缓存解析时仍沿用原 URL 的来源标识。新的候选走现有人工审核和实体合并流程；不会自动发布。

界面入口：知识库页面每个资料集合的论文列表下方有折叠的“资料版本与重新解析”，同一资料的多个版本只占一行；导入记录的“文件列表”中也能看到该次导入的文献版本。

启用按来源标识生效，影响该来源所在的所有集合。审核发布与启用是独立操作；未执行版本切换时，多个已发布且未被取代的版本可能同时可用。版本面板会如实列出这些版本。

启用确认弹窗会加载影响预览。只统计当前有有效的已发布证据、且启用后不再有有效证据的已发布实体和关系；新旧版本都有证据、其他有效来源仍有证据，或切回目标版本后能恢复证据的知识不计入损失。取代版本数沿用启用规则：同一来源标识、已发布且非目标的版本（含此前已被取代者）。预览不修改证据或审核记录；预览加载失败仍可启用，并显示风险提示。预览反映读取时的状态，后续审核或版本切换可能改变结果。

## 读取边界

- 项目研究：`KnowledgeContextReader` 在 SQLite 中排除被取代来源，Context Builder 的候选回读与提交前校验沿用该边界。
- 快速报告：Core 的论文授权范围、向量候选回读，以及图候选的正式知识读取均排除被取代来源；外部检索期间发生切换会重新核验范围。
- 知识图谱：节点、关系、证据计数、详情与待审叠加视图排除被取代来源的证据。
- 资料集合、知识条目与旧版图接口：过滤实时响应中的旧证据，不改写发布记录和审核历史。
- 已保存的快照、报告与运行继续读取冻结内容。Qdrant / Neo4j 无需删除旧投影。

## 集成与人工验收

1. 更新 API 与 Worker 后启动，结构迁移自动执行；不要只更新前端或继续运行旧 Worker。旧数据库不会自动重解析，也不会自动选定生效版本。
2. 选一份曾出现中文重复字或乱码、且本地 PDF 仍存在的旧文档，确认界面显示原解析版本。点击重新解析，在确认弹窗检查集合、审核与旧报告不变的说明。
3. 在原集合审核新候选；相同实体可合并到已有实体。审核发布后在“版本记录”启用新版本，检查检索、图谱与新研究引用新内容。
4. 打开已有报告和旧运行，核对原引文不变；切回旧版本后新检索应恢复旧证据。再次重解析同内容应提示无变化，或复用此前已存在的版本任务。
5. 无本地 PDF 的文档不能使用此入口；恢复登记路径处的原文件后再操作。

离线测试覆盖内容不变、新版本保留旧行、并发幂等、固定队列输入、审核前置条件、切换和回切、旧快照内容与哈希、残留向量及检索期间切换、迁移重放。浏览器布局检查使用离线接口数据，覆盖 1440 / 390 宽度；真实 PDF 与模型抽取效果仍需按上述步骤人工验收。
