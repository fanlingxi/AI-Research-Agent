目标：

构建一个面向长期项目的 Agent 工作空间。

核心：

Project

Task

Knowledge

Memory

Agent

Artifact

# 当前任务原则

你需要：

1.  先分析现有代码；
2.  理解已有架构；
3.  采用渐进迁移；
4.  保留已有能力。

禁止：

-   推倒重写；
-   无分析直接修改；
-   删除已有测试。

# 每次修改要求

输出：

1.  修改说明；
2.  修改文件；
3.  数据迁移影响；
4.  测试结果；
5.  后续建议。

------------------------------------------------------------------------

# Agent设计原则

采用：

LangGraph风格状态工作流。

不要：

AutoGPT无限循环。

------------------------------------------------------------------------

# Memory原则

保存：

-   项目状态；
-   决策；
-   产物。

不要保存：

全部聊天记录。

------------------------------------------------------------------------

# Knowledge原则

所有正式知识：

必须：

Evidence支持。

------------------------------------------------------------------------

# 最终目标

形成：

一个可展示、可扩展、本地运行的个人知识 Agent 平台。
